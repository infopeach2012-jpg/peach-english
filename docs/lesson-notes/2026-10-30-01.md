## レッスンノート

- **He might not get custody of his child.**
  - 和訳: 彼は子どもの親権を得られないかもしれません。
  - メモ: not get custody = 親権を得られない。すでにある親権を失う lose custody とは意味が異なります。

- **He might lose custody of his child.**
  - 和訳: 彼は子どもの親権を失うかもしれません。
  - メモ: lose custody = すでにある親権を失う。

- **He will lose his money because of his divorce.**
  - 和訳: 彼は離婚のためにお金を失うでしょう。
  - メモ: because of + 名詞 = ～のために。

- **He might have to file for bankruptcy.**
  - 和訳: 彼は自己破産を申し立てなければならないかもしれません。
  - メモ: file for bankruptcy = 破産を申し立てる。might have to = ～しなければならないかもしれない。

- **Couples shouldn't get a joint mortgage.**
  - 和訳: 夫婦は共同名義の住宅ローンを組まないほうがよいです。
  - メモ: joint mortgage = 共同の住宅ローン。

- **He will have to go bankrupt even if I help him.**
  - 和訳: 私が彼を助けても、彼は破産せざるを得ないでしょう。
  - メモ: go bankrupt = 破産する。even if = たとえ～しても。

- **Mr. Nakamura has to make his own decision, so I should just watch over him.**
  - 和訳: 中村さんは自分で決めなければならないので、私はただ見守るべきです。
  - メモ: make his own decision = 自分で決める。watch over = 見守る。

- **Please tell me the difference between near and close.**
  - 和訳: near と close の違いを教えてください。
  - メモ: the difference between A and B = AとBの違い。場所の近さでは near ～ / close to ～ の形を使います。

- **We don't know what happened between him and his wife, but I trust him.**
  - 和訳: 彼と奥さんの間に何があったのかは分かりませんが、私は彼を信頼しています。

- **He is going to a law firm.**
  - 和訳: 彼は法律事務所に行くところです。
  - メモ: law firm = 法律事務所。lawyer = 弁護士。「事務所に行く」と「弁護士に会う」は厳密には同じ意味ではありません。

- **He is going to see a female lawyer.**
  - 和訳: 彼は女性の弁護士に会う予定です。
  - メモ: be going to see = ～に会う予定。female lawyer = 女性の弁護士。

- **It's easy to use English when shopping, traveling, or having everyday conversations.**
  - 和訳: 買い物や旅行、日常会話では英語を使いやすいです。

- **I have started speaking English surprisingly well.**
  - 和訳: 驚くほど上手に英語を話せるようになってきました。
  - メモ: surprisingly well = 驚くほど上手に。

- **We are always arguing about the AC temperature.**
  - 和訳: 私たちはいつもエアコンの温度について言い争っています。
  - メモ: be always -ing は、繰り返す行動への不満を表すことがあります。AC = air conditioning。

- **We haven't figured out how to use it.**
  - 和訳: 私たちはまだその使い方が分かっていません。
  - メモ: figure out = 理解する・分かる。how to use it = それの使い方。

- **It's freezing cold.**
  - 和訳: 凍えるほど寒いです。
  - メモ: freezing cold は強い寒さを表します。

- **It's freezing.**
  - 和訳: 凍えるほど寒いです。
  - メモ: freezing だけでも「凍えるほど寒い」という意味になります。

- **I am creating an AI system for practicing speaking and listening in English this week.**

- **I have been creating an AI system for a week, and I will finish it today.**

- **I've finished creating the system for my company.**
  - 和訳: 会社のためのシステムを作り終えました。
  - メモ: finish + -ing = ～し終える。

- **We have a lot of meat left in stock.**
  - 和訳: 肉の在庫がたくさん残っています。
  - メモ: left in stock = 在庫として残っている。

- **How do you choose meat when you shop?**

- **This system is designed to help my employees practice talking to clients.**

  - メモ: be designed to = ～するために設計されている。practice + -ing = ～する練習をする。

- **The system provides many different practice scenarios for my employees.**
  - 和訳: このシステムは、従業員向けにさまざまな練習場面を提供します。

- **It has three different levels: beginner, intermediate, and advanced.**
  - 和訳: 初級・中級・上級の3つのレベルがあります。

- **My client agreed to help me with the system.**
  - 和訳: 取引先が、このシステムについて協力することに同意してくれました。
  - メモ: agree to + 動詞 = ～することに同意する。help someone with ～ = ～について人を手伝う。

- **I'm not sure if they will keep using the system.**
  - 和訳: その人たちがこのシステムを使い続けるかは分かりません。
  - メモ: keep + -ing = ～し続ける。not sure if = ～かどうか確信がない。

- **I want you to try the system.**
  - 和訳: あなたにこのシステムを試してほしいです。
  - メモ: want + 人 + to + 動詞 = 人に～してほしい。

- **I've decided to study English.**
  - 和訳: 英語を勉強することに決めました。
  - メモ: to不定詞：これからすることを表す場合が多いですが、必ず未来を表すわけではありません。 decide to = ～することに決める。

- **I've planned to go to Tohoku.**
  - 和訳: 東北に行く計画を立てました。
  - メモ: to不定詞：これからすることを表す場合が多いですが、必ず未来を表すわけではありません。 plan to = ～する計画を立てる。

- **I want to go abroad.**
  - 和訳: 海外に行きたいです。
  - メモ: to不定詞：これからすることを表す場合が多いですが、必ず未来を表すわけではありません。 want to = ～したい。

- **I keep dancing.**
  - 和訳: 私は踊り続けます。
  - メモ: 動名詞：動作・活動を名詞として表す形。現在や過去の行為を指す場合も多いですが、時点は文脈で決まります。 keep + -ing。

- **I enjoy speaking English.**
  - 和訳: 英語を話すことを楽しんでいます。
  - メモ: 動名詞：動作・活動を名詞として表す形。現在や過去の行為を指す場合も多いですが、時点は文脈で決まります。 enjoy + -ing。

- **I practice swimming.**
  - 和訳: 水泳の練習をしています。
  - メモ: 動名詞：動作・活動を名詞として表す形。現在や過去の行為を指す場合も多いですが、時点は文脈で決まります。 practice + -ing。

- **I'll stop to smoke.**
  - 和訳: タバコを吸うために立ち止まります。
  - メモ: stop to do = ～するために、それまでの動作を止める。

- **I've stopped smoking.**
  - 和訳: タバコを吸うのをやめました。
  - メモ: stop doing = ～するのをやめる。この文では禁煙したことを表します。

- **I'll remember to call you.**
  - 和訳: 忘れずにあなたに電話します。
  - メモ: remember to do = 忘れずに～する（これからすること）。

- **I remember calling you.**
  - 和訳: あなたに電話したことを覚えています。
  - メモ: remember doing = ～したことを覚えている（すでにしたこと）。

## Speakの表現

- **I have to pick up my dog from the groomer.**
  - 和訳: トリマーさんに愛犬を迎えに行かなければなりません。
  - メモ: pick up = 迎えに行く・受け取る。groomer = ペットのトリマー。

- **I have to pick up my clothes from the dry cleaner.**
  - 和訳: クリーニング店に服を取りに行かなければなりません。
  - メモ: pick up = 取りに行く。dry cleaner = ドライクリーニング店。

- **running errands**
  - 和訳: 用事を済ませること
  - メモ: run errands = 買い物などの用事を済ませる。

- **Actually, how about staying in?**
  - 和訳: それより、家でゆっくりするのはどうですか？
  - メモ: Actually, how about ～? = それより、～はどう？ how about + -ing。stay in = 外出せず家で過ごす。

- **Actually, how about getting a drink?**
  - 和訳: それより、一杯飲むのはどうですか？
  - メモ: how about + -ing = ～するのはどう？ get a drink = 一杯飲む。

- **Audrey has a ton of chores.**
  - 和訳: Audreyには山ほど家事があります。
  - メモ: a ton of = たくさんの（くだけた表現）。chores = 家事・雑用。

- **Sure thing!**
  - 和訳: もちろんです！
  - メモ: 依頼に気軽に応じる表現。

- **They're just not for me.**
  - 和訳: それらは私にはちょっと合いません。
  - メモ: not for me = 自分の好みや性格には合わない。
