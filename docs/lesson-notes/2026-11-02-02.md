## 11月2日追加② · pick out（選ぶ）

- **She has to pick out a dress for the wedding.**
  - 和訳: 彼女は結婚式に着ていくドレスを選ばなければならない。
  - メモ: 画像1の英文・和訳を転記。補足: pick out = いくつかの中から選ぶ。主語が she のため have to ではなく has to。has to の後ろは動詞の原形 pick。for the wedding = 結婚式のために・結婚式に着ていくために。

- **I have to pick out a few options.**
  - 和訳: いくつかの候補を選ばなきゃいけません。
  - メモ: 画像5の英文・和訳を転記。補足: have to = ～しなければならない。a few = いくつかの。options = 選択肢・候補。pick out は候補の中から選ぶことで、試着する try on とは区別する。

- **I have to pick out a gift.**
  - 和訳: ギフトを選ばなきゃいけません。
  - メモ: 画像8の英文・和訳を転記。補足: pick out a gift = 贈り物を選ぶ。gift = 贈り物・プレゼント。a gift は1つの贈り物。

## 11月2日追加② · try on（試着する）

- **Not yet. I have to try on a few options.**
  - 和訳: まだです。いくつかの候補を試着しなきゃいけません。
  - メモ: 画像4の英文・和訳を転記。補足: Not yet. = まだです・まだしていません。try on = 服や靴などを試着する。この場面の options は試着する服などの候補を指す。a few は「いくつかある」という意味。

- **I have to try on a different size.**
  - 和訳: 別のサイズを試着してみなきゃいけません。
  - メモ: 画像6の英文・和訳を転記。補足: a different size = 別のサイズ。different だけでは、大きいサイズか小さいサイズかまでは指定しない。try on は実際に身に着けて試すこと。

- **I have to try on some new shoes.**
  - 和訳: 新しい靴を試着してみなきゃいけません。
  - メモ: 画像7の英文・和訳を転記。補足: 靴にも try on を使い、「試し履きする」と言える。some new shoes = 新しい靴。shoes は通常複数形で表し、一足を明確に数えるなら a pair of shoes を使う。

## 11月2日追加② · drop off（届ける・預ける）

- **They have to drop off their luggage.**
  - 和訳: 彼らは荷物を預けなければなりません。
  - メモ: 画像2の英文・和訳を転記。補足: drop off は物を目的の場所へ持っていって置く・届けること。この場面では luggage（手荷物）を預けるという意味。luggage は数えられない名詞として扱い、通常 a luggage や luggages とはしない。

- **We have to drop off the donations.**
  - 和訳: 私たちは寄付品を届けに行かなければなりません。
  - メモ: 画像3の英文・和訳を転記。補足: donations は寄付金や寄付品を指し、この場面では持っていく寄付品。drop off the donations = 寄付品を届ける。受け取りに行く pick up とは向きが異なる。

## 11月2日追加② · pick up（買ってくる）

- **I have to pick up some groceries.**
  - 和訳: 食料品を買わなきゃいけません。
  - メモ: 画像9の英文・和訳を転記。補足: pick up は物を取りに行く・受け取る意味があり、groceries と組み合わせると「食料品を買ってくる」という意味になる。人を目的語にすると「迎えに行く」にもなる。pick out（選ぶ）と区別する。

## 4つの表現の使い分け（補足）

| 表現 | 今回の場面での意味 | 画像の例 |
| --- | --- | --- |
| pick out | 選ぶ | ドレス・候補・ギフトを選ぶ |
| try on | 試着する・試し履きする | 別のサイズ・新しい靴を試す |
| drop off | 届ける・預ける | 寄付品を届ける、荷物を預ける |
| pick up | 買ってくる・受け取る | 食料品を買ってくる |

これらは目的語や場面によって意味が変わります。たとえば pick up は人なら「迎えに行く」にもなります。have to は「～しなければならない」で、she / he / it では has to を使います。
