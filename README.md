# Speak Studio 🗣️ — 英会話トレーニングアプリ

「**スピーク**」（実際に声に出して話す発音採点）と「**スピークバディ**」（AIキャラとのロールプレイ会話・カリキュラム・ゲーミフィケーション）の**いいとこ取り**をした、渡辺さん専用の英会話練習アプリです。

Excel教材（`1a29c82a-___________.xlsx`）の学習コンテンツを取り込み（2026-10-14 英語学習スクリーンショット218枚のOCRから519件を追加）、ブラウザだけで動く軽量SPAとして構築しています。ビルド不要・完全静的。

## 使い方

```bash
# リポジトリ直下でHTTPサーバを起動（fetch と localStorage のため file:// は不可）
python3 -m http.server 8000
# → http://localhost:8000/english-app/ を Chrome / Edge / Safari で開く
```

音声認識（発音採点）には **Chrome / Edge / Safari** を推奨します（Web Speech API）。マイクの許可が必要です。

ライト／ダーク／自動（OS設定に追従）のテーマに対応（ホームの「設定」から切替）。

### AI会話について

Anthropic APIキーが必要です（経営分析AIと同じ `peach.anthropicApiKey` を共用）。すでにCRMでキーを設定済みなら追加設定なしで使えます。未設定の場合は会話開始時に入力欄が出ます。キーは端末内(localStorage)に保存され、Anthropic以外へは送信されません。会話モデルはテンポ重視で Haiku 4.5 を使用。

### PWA（ホーム画面に追加）

`manifest.webmanifest` ＋ Service Worker（`sw.js`）でインストール可能。スマホのブラウザで「ホーム画面に追加」すると、ネイティブアプリのように全画面で起動し、オフラインでも学習コンテンツ（AI会話を除く）が動作します。

## ゲーミフィケーション

- **XP / レベル**：学習アクションごとにXP獲得、レベルアップ演出
- **ストリーク（🔥）**：連続学習日数を記録
- **1日の目標**：デフォルト15項目（ホームの設定で変更可）
- **SRS**：カードの覚え具合（もう一度／難しい／普通／簡単）で次回出題日を自動調整
- **達成バッジ**：連続日数・発話回数・発音100点・レベル・カード習得など12種のバッジ。条件達成で獲得演出（統計ページに一覧）

進捗はすべてブラウザの `localStorage`（`speak.progress.v1`）に保存されます。端末間では共有されません。ホーム下部の「設定・進捗リセット」から初期化できます。

## 発音スコアリングの仕組み

お手本テキストと音声認識結果を単語単位で照合し、一致率（%）で採点します。短縮形（`we're`→`we are`）・数字（`7`→`seven`）・語尾変化の表記ゆれを吸収し、レーベンシュタイン距離で近似一致も許容します。認識できなかった語は赤、できた語は緑でハイライトされます。

> 完全静的なため GitHub Pages / Netlify / Vercel にそのままデプロイ可能です。

## スマホで開ける1ファイル版（2026-10-14〜）

`SpeakStudio.html` は、アプリ全体（画面・教材データ・Chart.js・Tailwind）を1つのHTMLにまとめた版。
**サーバー不要・オフラインで動く。** GitHubからダウンロードしてスマホに保存し、そのまま開く。
AI会話だけは通信とAPIキーが要る。進捗は端末のブラウザに保存される。

教材を更新したら作り直す: `python3 scripts/build_english_single.py`
（Tailwind は `vendor/tailwind.min.css` に事前コンパイル。クラス名を増やしたときの再コンパイル手順はスクリプト冒頭に記載）

## 聞き流し（2026-10-14〜）

ボトムナビの「聞き流し」。**フレーズ・単語**は14の場面（あいさつ／仕事／食事／買い物／健康／旅行／家／趣味／学校／予定／気持ち／人間関係／スマホ／単語・文法）で選び、英語→和訳の順に連続再生。**長文**は章ごとに文をハイライトしながら自動で進み、章の最後まで行くと次の章へ。速さ・和訳の有無・繰り返し回数・文の間を設定できる。
場面分けは `data/situations.json`（フレーズp番号・会話d番号 → 場面キー）。

## 自然な音声（2026-10-14〜）

`audio/` に Kokoro（ニューラルTTS・声は `af_heart`）で作った英語音声が入っている。場面・章ごとに1つのMP3に連結し、`audio/audio_index.json` が文ごとの開始秒と長さを持つ。`js/speech.js` が区間再生し、無い文だけ端末の読み上げに戻る。作り直すときは `for_chatgpt/generate_audio.py`（手順はファイル冒頭）。file:// で開く1ファイル版には音声は入らない。
