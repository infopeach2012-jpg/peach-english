# Speak Studio 🗣️ — 英会話トレーニングアプリ

「**スピーク**」（実際に声に出して話す発音採点）と「**スピークバディ**」（AIキャラとのロールプレイ会話・カリキュラム・ゲーミフィケーション）の**いいとこ取り**をした、渡辺さん専用の英会話練習アプリです。

Excel教材（`1a29c82a-___________.xlsx`）の学習コンテンツを取り込み（2026-10-14 英語学習スクリーンショット218枚のOCRから519件を追加）、ブラウザだけで動く軽量SPAとして構築しています。ビルド不要・完全静的。

## 使い方

```bash
# リポジトリ直下でHTTPサーバを起動（fetch と localStorage のため file:// は不可）
python3 -m http.server 8000
# → http://localhost:8000/english-app/ を Chrome / Edge / Safari で開く
```

音声認識（発音採点）には **Chrome / Edge / Safari** を推奨します（Web Speech API）。マイクの許可が必要です。

ライト／ダーク／自動（OS設定に追従）のテーマに対応（ホームの「設定」から切替）。

### AI会話について

Anthropic APIキーが必要です（経営分析AIと同じ `peach.anthropicApiKey` を共用）。すでにCRMでキーを設定済みなら追加設定なしで使えます。未設定の場合は会話開始時に入力欄が出ます。キーは端末内(localStorage)に保存され、Anthropic以外へは送信されません。会話モデルはテンポ重視で Haiku 4.5 を使用。

### PWA（ホーム画面に追加）

`manifest.webmanifest` ＋ Service Worker（`sw.js`）でインストール可能。スマホのブラウザで「ホーム画面に追加」すると、ネイティブアプリのように全画面で起動し、オフラインでも学習コンテンツ（AI会話を除く）が動作します。

## ゲーミフィケーション

- **XP / レベル**：学習アクションごとにXP獲得、レベルアップ演出
- **ストリーク（🔥）**：連続学習日数を記録
- **1日の目標**：デフォルト15項目（ホームの設定で変更可）
- **SRS**：カードの覚え具合（もう一度／難しい／普通／簡単）で次回出題日を自動調整
- **達成バッジ**：連続日数・発話回数・発音100点・レベル・カード習得など12種のバッジ。条件達成で獲得演出（統計ページに一覧）

進捗はすべてブラウザの `localStorage`（`speak.progress.v1`）に保存されます。端末間では共有されません。ホーム下部の「設定・進捗リセット」から初期化できます。

## 発音スコアリングの仕組み

お手本テキストと音声認識結果を単語単位で照合し、一致率（%）で採点します。短縮形（`we're`→`we are`）・数字（`7`→`seven`）・語尾変化の表記ゆれを吸収し、レーベンシュタイン距離で近似一致も許容します。認識できなかった語は赤、できた語は緑でハイライトされます。

> 完全静的なため GitHub Pages / Netlify / Vercel にそのままデプロイ可能です。

## 聞き流し（2026-10-14〜）

ボトムナビの「聞き流し」。**フレーズ・単語**は14の場面（あいさつ／仕事／食事／買い物／健康／旅行／家／趣味／学校／予定／気持ち／人間関係／スマホ／単語・文法）で選び、英語→和訳の順に連続再生。**長文**は章ごとに文をハイライトしながら自動で進み、章の最後まで行くと次の章へ。速さ・和訳の有無・繰り返し回数・文の間を設定できる。

## 自然な音声（2026-10-14〜）

**Kokoro v1.0（kokoro-onnx 0.6.1）・`af_sarah`（アメリカ英語・女性）** を使用。2026-10-29に再生成し、2026-10-30に速度追加・全件検査を実施し、同日の教材追加で46件・230ファイルを追加しました。現在はフレーズ・単語・ノート・会話・長文・スピーチ・パターン練習・AI会話の開始文の計3,081件について、5速度・計15,405ファイルを `audio/clips/` に保存しています。MP3はモノラル・24 kHz・112 kbpsです。

**標準は0.75倍**。ユーザー提供のSpeak動画と同じ3文を比較し、平均の発話テンポを参考に調整しました。0.6 / 0.75 / 1 / 1.25 / 1.5倍から選べ、AI会話を含めて各画面で設定を共有・保存します。倍率の1は従来の音声の速さです。保存音声は事前に速度変換した専用ファイルを再生し、端末内での引き伸ばしを避けています。AIの動的な返答には端末TTSの速度設定を適用します。[比較データ・全件検査の結果](docs/audio-audit-2026-10-30.md)。

`audio/audio_index.json` はキーから拡張子なしの相対ファイル名への対応表（例: `p1` → `clips/p1`、`p1@slow` → `clips/p1_slow`）。長文は文ごと、スピーチは同じ `section` をつないで文ごとに分割している。`js/speech.js` が音声を再生し、無い文だけ端末の読み上げに戻る。置き方とキーの仕様は `for_chatgpt/音声の仕様_Codex向け.md`。`for_chatgpt/generate_audio.py` は従来の場面別連結形式（B）用。file:// で開く1ファイル版には音声は入らない。

## AI会話の再生修正（2026-10-30）

「言いたいことを、言葉に。」のAI会話で、保存済みの最初の音声はMP3、毎回変わるAIの返答は端末の読み上げを使います。

- MP3と端末の読み上げを同時に鳴らさず、切り替え時には前の再生を終了します。端末が停止イベントを返さない場合にも、停止待ちを残しません。
- MP3の先読み・再生準備では、使わないAudioContextを起動しません。対応するiPadでは[Audio Session API](https://developer.mozilla.org/en-US/docs/Web/API/AudioSession/type)を使い、マイク終了後にスピーカー再生の設定へ戻します。
- 会話から移動・場面変更した後に、遅れて届いたAIの返答が鳴り始めることを防ぎます。「ゆっくり」は端末の読み上げにも適用します（v35から0.6倍）。
- 既存の12,140本のMP3は全てデコード可能で、波形のクリッピングは0本、最大ピークは約−3.27 dBFSでした。このv34の修正時点では音声ファイルとデザインは変更していません。v35では0.6倍版を追加しています。
- 回帰テスト: `node --test tests/speech.test.cjs`。ブラウザでも実MP3の再生・AI会話の切り替えを確認（AI応答と音声認識はモック）。iPad実機のスピーカー出力は、この環境では測定できません。
